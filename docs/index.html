Everything the 2003 game does — in your pocket

Campaign, skirmish and the Generals Challenge run unmodified. Everything around the engine was rebuilt for a phone.

🖥️

Two native renderers

OpenGL ES 3.0 (DX8 → GLES, written for this port) is the default and works on every device tested so far. Vulkan via DXVK is one tap away and faster where the driver handles it — with an adaptive Vulkan 1.1 fallback for Mali GPUs.

👆

Touch built for RTS

Tap-select, drag-box, two-finger pan/zoom, long-press cancel, ability aiming that follows your finger, a second command-bar page. Orders are identical to the mouse path — multiplayer and replays are unaffected.

🌐

Online, with PC players

GeneralsOnline: lobby, custom match, quickmatch, persona stats, friends. The phone speaks the PC client's protocol and matches its checksums — cross-play since v1.3.0. P2P transport with native ICE/STUN/TURN.

🗂️

Launcher with zero adb

One home-screen icon opens a launcher: in-app folder picker, log viewer with Clear/Share, GeneralsOnline account & network data, language packs and updates. No PC needed, fully offline-capable.

🌍

13 languages

English plus 12 complete packs — including Arabic and Persian with real right-to-left layout and letter shaping, and CJK glyphs from your phone's own fonts. Add yours — no app update needed.

🔄

Updates without a new APK

Signed engine builds and network settings arrive straight from this repository (Home → Updates). Anything unsigned is ignored; a broken engine update rolls itself back. 30 Hz retail and 60 Hz sim ship in the same APK.

FAQ

Is this official? Is it legal?

No — it's an unofficial, community-made fan port of EA's own GPL v3 source release, not affiliated with or endorsed by EA. The engine code is GPL v3; Command & Conquer remains an EA trademark and no game assets are included or distributed — you must own the game (Steam, ~$5 on sale).

Which phones does it run on?

Android 9+ on arm64. The GLES renderer works on every device tested so far. Vulkan is fastest on Adreno 7xx/8xx, falls back adaptively on Vulkan-1.1-only Mali (playable, CPU-bound), and simply can't run on some drivers (PowerVR BXM, Samsung Xclipse) — the GLES default covers those.

Do I really play against PC players?

Yes — real lobbies and real matches since v1.3.0. Turn on “Play with PC players” in the launcher, install the Online game data there, and the PC side turns its anti-cheat off so the server matches you.

Magenta textures or corrupted graphics?

Usually missing base-Generals archives (Terrain.big, Textures.big, W3D.big) — Setup names any missing archive and can point at a separate base-game folder. If it's the Vulkan driver, switch to GLES in Setup → Render Backend. The log tells you which: [gxmiss] … is game files, [d3d8gles] MAGENTA: is format support.

How do I install it?

Grab the APK from Releases and sideload it — newer builds install over older ones (same signing key). Open the game's icon, pick your game folder, done. Full walkthrough: docs/port/ANDROID_PORT.md.
